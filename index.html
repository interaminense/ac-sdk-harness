ac-sdk-harness

Interactive, in-browser test pages for Liferay's Analytics Cloud client SDK (analytics-client-js). Each page loads a real build of the SDK and shows — live — which analytics events it emits as you drive the page. Events are real: they are queued and flushed to the dev backend below.

All events 29 events

Smoke test for every triggerable event. Click Run all and watch the checklist go green — page view, asset views and impressions, clicks, downloads, submits, field focus/blur, scroll depth, read, and the lifecycle events (load, tab blur/focus, unload).

Events on load

The view/impression events that fire as assets enter the viewport on page load, across all six application types. Toggle individual asset boxes on and off to see how the load-time events change.

Reveal scenarios all view/impression

Every plugin's view and impression assets, each hidden by an ancestor (a closed menu, opacity:0, visibility:hidden) and revealed via a toggle. With the visibility fix the events fire only on reveal; until it ships to the dev CDN they fire on load.
