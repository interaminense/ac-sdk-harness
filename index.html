ac-sdk-harness

Interactive, in-browser test pages for Liferay's Analytics Cloud client SDK (analytics-client-js). Each page loads a real build of the SDK and shows — live — which analytics events it emits as you drive the page. Events are real: they are queued and flushed to the dev backend below.

All events 29 events

Smoke test for every triggerable event. Click Run all and watch the checklist go green — page view, asset views and impressions, clicks, downloads, submits, field focus/blur, scroll depth, read, and the lifecycle events (load, tab blur/focus, unload).

Events on load

The view/impression events that fire as assets enter the viewport on page load, across all six application types. Toggle individual asset boxes on and off to see how the load-time events change.

Reveal scenarios all view/impression

Every plugin's view and impression assets, each hidden by an ancestor (a closed menu, opacity:0, visibility:hidden) and revealed via a toggle. With the visibility fix the events fire only on reveal; until it ships to the dev CDN they fire on load.

pageUnloaded unload deprecation

Chrome is retiring unload, which is where the SDK used to report pageUnloaded from. Identifies which lifecycle event the loaded build listens for, captures a real departure across a navigation, and covers the back/forward cache cases the move to pagehide opens up. Takes ?sdk=local to drive a locally built bundle.

setIdentity fields LPD-103257

The optional fields array on setIdentity(). Shows the exact /identity request body on the wire, and probes that the fields are normalized by name, that reordering them is deduplicated, that a changed value still gets through, and that a legacy call is untouched. Takes ?sdk=local to drive a locally built bundle.

flush() LPD-103258

Analytics.flush() — send everything queued now and wait for it. Runs with a 10 minute flush interval so the loop never fires, then probes that the Promise settles after the request rather than before, that an empty queue is free, and that a hanging endpoint still settles on REQUEST_TIMEOUT. Measures the sequential-queue ceiling too.

Marketo form LPD-103259

The integration script driven against a stand-in for the liferay.com/request-a-demo form — same Marketo form id and field names, hidden campaign fields included. Checks that only the five mapped fields go out, that the email travels hashed and in plaintext, that Marketo's own redirect is suppressed, and that the navigation waits for the request.

Cookie domain LPD-102209

The anonymous user id cookie shared across sibling subdomains. Probes that the id is published at the configured domain rather than at this host, that a host with no id of its own adopts the shared one, that a previous version's host-only cookie is retired instead of coexisting, and that an identified visitor is left alone. Reports which id wins when both exist, because the story and the branch disagree there. Reach it through two *.localhost names to watch a real second host adopt the id.
