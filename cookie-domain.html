Cookie domain

Drives the anonymous user id cookie shared across sibling subdomains (LPD-102209). The client takes a cookieDomain the server computes per request and, when it holds one, writes ac_client_user_id at that domain instead of at this exact host — so every host under it answers with one id. Load a different build with ?sdk=<url> (?sdk=local resolves to ./local/analytics-all-min.js) and override the domain under test with ?cookieDomain=<domain>.

Probes

Each probe seeds a starting state, then disposes and re-creates the client — the same path DXP takes on an SPA navigation, so the client re-runs _ensureIntegrity() and re-reads the cookie exactly as it would on a page load. A cookie written by a sibling subdomain is indistinguishable from one written here with the same domain=, which is what makes a single host enough to drive the adoption logic. The last probe waits for the identity queue, so a full run takes a few seconds.

State

Live view of the three places an id can sit, plus the buttons to put one there by hand. Reload after seeding to watch the client decide. Unlike the other harness pages, this one does not clear ac_* on load — what survives a load is exactly what is under test, and wiping would delete the id a sibling subdomain just published.

Checking it across two real hosts

The probes drive the client's decision in full, but only a second real hostname proves the browser hands the cookie over. Any *.localhost name resolves to the loopback address with no /etc/hosts entry, and browsers treat those names as a secure context — which matters, because the client marks the cookie Secure. Serve this directory and reach it through two names:

  1. Open http://a.test.localhost:8000/cookie-domain.html, clear everything, and reload. This host mints an id and publishes it at test.localhost.
  2. Open http://b.test.localhost:8000/cookie-domain.html and clear localStorage only. It adopts the same id instead of minting a second one.
  3. Give b an id of its own (clear everything there, reload), then reload a. Whichever end gives way tells you the same thing the which id wins probe reports.
