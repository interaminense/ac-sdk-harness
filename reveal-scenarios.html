Reveal scenarios — ancestor-hidden view / impression tracking

Every plugin's view and impression assets, each sitting inside a container that an ancestor hides via visibility + opacity (the liferay.com mega-menu case). Reveal a card and watch its view / impression events fire.

Note: this page loads the live SDK from analytics-js-dev-cdn.liferay.com. The visibility-gating fix (LPD-99067) is not yet deployed there, so the current build fires these events on load (geometry only) rather than on reveal. Once the fix ships to the CDN, the events will fire only when a card is actually revealed.
